# T122 Create a Scout character

OPEN AT: The new Scout character at the first skill-table choice: the service badge, rank, age and skills are visible beside Personal development, Special skills, Education and Advanced education.
SETUP KEYS: From the title: Start game > Start New Game > Use Default Characters > Create New Character > Yes > Enlist > Scouts. Headless proof: acceptance/local/atoms/122.json; the window cannot load character-creation snapshots, so use this menu path. Live dice may differ.
ACTIONS:
  1. Click Personal development for each skill roll [Enter]; when a specialty window opens, click its first choice [Enter]
  2. Click Muster Out when the term ends [Down, Enter]
  3. Click Cash for each mustering-out selection [Right, Enter]
  4. Click the name box, type AtomScouts and confirm [Enter]
  5. Click View Character [arrow keys, Enter], then click AtomScouts [arrow keys, Enter]
EVALUATE:
  - The badge names Scouts and the first term has reached its skill choices
  - Finishing the term records the chosen skills and attribute gains; mustering out offers benefits or cash
  - The named character appears in View Character with the same service
