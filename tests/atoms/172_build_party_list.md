# T172 Add and remove a Traveller from the party

OPEN AT: The party-building menu with Jurgen alone in the Party list on the right. Add to Party, Remove From Party and Play Game are available.
SETUP KEYS: From the title: Start game > Start New Game > Use Default Characters > Add to Party > Jurgen. Headless snapshot: acceptance/local/atoms/172.json; this build cannot open character-creation snapshots in the game window.
ACTIONS:
  1. Click Add to Party, then Verti [arrow keys, Enter for each choice]
  2. Click Remove From Party, then Jurgen [arrow keys, Enter for each choice]
  3. Click Add to Party and check the names offered [arrow keys, Enter]; close the list [Esc]
EVALUATE:
  - Adding Verti puts her name beside Jurgen in the Party list.
  - Removing Jurgen leaves Verti in the Party list.
  - Jurgen is available to add again; Verti is absent from the available names because she is already in the party.
