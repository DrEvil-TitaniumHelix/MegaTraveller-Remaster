# T052 Set up by dropping the folder

OPEN AT: The first-run screen with the drop box
SETUP KEYS: folder acceptance/local/atoms/setup51, start the exe inside it
ACTIONS:
  1. Read the screen
  2. Drag the folder MegaTra1 (Explorer window "MegaTraveller (1990)", opened for you) onto the game window
  3. Press Enter
  4. Press any key
EVALUATE:
  - Only ONE window opened (no black console window beside it)
  - It looks like a game's start screen: the title "MegaTraveller 1 Plus" on a purple band, one sentence why, a blue box in a dashed frame with "Drop the folder of your original MegaTraveller 1 game here", under it "It is the folder that contains the file TRAV.COM", a button "Choose folder...", and "Esc quits."
  - No folder path, no file names, no numbers of files, nothing red
  - After the drop: "Found the game in the folder "MegaTra1"." and the box "Press Enter or click here to copy its files"
  - After Enter: "The files of the game are copied." and "Press any key or click here to play"
  - After the key: the original title
