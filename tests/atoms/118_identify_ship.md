# T118 Identify another ship at Communications

OPEN AT: The Communications station during an Efate encounter, Verti at COMMO, the system directory at left and quadrant information at right.
SETUP KEYS: snapshot acceptance/local/atoms/118.json
ACTIONS:
  1. Click the upper-left corner of the Communications panel, just below the station strip, to identify a ship [X]
  2. Click the other ship on the tactical map [Enter selects the highlighted ship]
  3. Read the identification report
  4. Close the report [Esc]
EVALUATE:
  - Identify opens the tactical map with a ship to select
  - Selecting the ship returns a report with its type, cargo, condition and weapons
  - Closing the report returns to the communications directory
