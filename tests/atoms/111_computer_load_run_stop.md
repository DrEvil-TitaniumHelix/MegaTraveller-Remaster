# T111 Load, run and stop a computer program

OPEN AT: The Interloper's Computer station at Efate, Dennar at the controls, no program loaded, Navigation available to load.
SETUP KEYS: snapshot acceptance/local/atoms/111.json
ACTIONS:
  1. Click Load [L], click the Navigation icon [Enter], then the first computer slot [Enter]
  2. Wait until loading finishes
  3. Click Run [R], then the Navigation slot [Enter]
  4. Click Stop [S], then the Navigation slot [Enter]
EVALUATE:
  - Load offers Navigation and places it in the chosen slot
  - The loading indicator finishes before the program can run
  - Run lights the running indicator; Stop clears it while Navigation stays loaded
