# T198 Load the saved character pool with Use My Party Disk

OPEN AT: The new-game menu offering Use My Party Disk, Create Party Disk and Use Default Characters. This snapshot has a saved sample pool of eight characters, with Jurgen removed.
SETUP KEYS: Open snapshot acceptance/local/atoms/198.json. Its replay creates the sample character disk inside this snapshot session; no existing party disk is needed.
ACTIONS:
  1. Click Use My Party Disk [Enter on the first row]
  2. Click View Character [Up/Down to View Character, Enter]
  3. Read the saved names, then close the name list [Esc]
EVALUATE:
  - Use My Party Disk opens the character-pool menu with Save Character Pool available and an empty Party list
  - View Character lists Verti, Dennar, Effane, Magellan, Alaric, Ripley, Ace and Alexandra; Jurgen is absent, as in the saved sample
  - Closing the name list returns to the pool menu without adding anyone to the Party list
