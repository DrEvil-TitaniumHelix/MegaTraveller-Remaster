# T057 Roll attributes

OPEN AT: The MegaTraveller title screen
SETUP KEYS: normal launch with no snapshot: the title cannot be restored (the snapshot launch refuses title and character generation); acceptance/local/atoms/057.json is the headless frame proof only
ACTIONS:
  1. Press Space on the title
  2. Press Enter on Start New Game
  3. Press Down, then Enter on Create Party Disk (if it asks whether to erase the characters on the disk, answer Yes: they are only test characters in this build)
  4. Press Enter on Create New Character
EVALUATE:
  - The game menu shows Start New Game, Continue Old Game and Get Started Quick
  - Start New Game offers Use My Party Disk, Create Party Disk and Use Default Characters
  - Create Party Disk opens the character pool: Create New Character, Save Character Pool, View Character, Add to Party
  - Create New Character asks its first question with Yes and No
