# T171 Read a supplied character before choosing a party

OPEN AT: Jurgen's character sheet from the default character pool, with his Scouts badge, attributes, skills and equipment visible.
SETUP KEYS: From the title: Start game > Start New Game > Use Default Characters > View Character > Jurgen. Headless snapshot: acceptance/local/atoms/171.json; this build cannot open character-creation snapshots in the game window.
ACTIONS:
  1. Close the sheet [Space]
  2. Click View Character, then Verti [arrow keys, Enter for each choice]
  3. Read Verti's sheet, then close it [Space]
EVALUATE:
  - The first sheet names Jurgen and displays his character details.
  - Choosing Verti shows a different name and character details.
  - Closing each sheet returns to the party-building menu without adding anyone to the Party list.
